# Basis Kode (Source Code): Smart E-Voting BEM-DPM

Direktori ini menampung implementasi kode sumber aplikasi:

- **`mobile/`**: Aplikasi klien antarmuka Flutter (Dart) yang mendukung build native Android, iOS, dan Flutter Web (PWA).
- **`backend/`**: Layanan RESTful API, pipeline integrasi AI OCR, dan manajemen transaksi database ACID.
