# Project Brief: Smart E-Voting BEM-DPM

## Latar Belakang
Aplikasi ini dibangun untuk memfasilitasi proses pemilihan ketua BEM dan anggota DPM di tingkat kampus secara digital agar lebih mudah, aman, dan transparan.

## Tujuan Utama
1. Mempermudah mahasiswa memberikan suaranya dari mana saja.
2. Memastikan keamanan dan satu mahasiswa hanya bisa memvoting satu kali.
3. Menampilkan penghitungan hasil suara yang lebih cepat dan akurat.

## Target Pengguna
- Mahasiswa aktif (sebagai pemilih).
- Panitia pemilihan (sebagai admin untuk memantau berjalannya sistem).
